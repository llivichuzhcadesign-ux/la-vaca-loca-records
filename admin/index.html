01 / Overview

Content dashboard

This admin layer reads the same SITE_CONTENT structure used by the public site, saves local drafts in this browser, and prepares the publishing workflow.

Current stage: prototype only. Changes save locally in the browser and can be previewed with ?preview=admin-draft, then exported as a complete data.js file. They do not publish automatically yet.

This creates a complete replacement for data.js. Save the draft, preview it on the public site, copy or download the file, then publish it manually until we connect the admin to GitHub or storage.

Publishing workflow
  1. Edit records, sessions, events, archive, and settings.
  2. Save the local draft.
  3. Open draft preview to see the public site using saved admin content.
  4. Copy or download the generated data.js file.
  5. Replace data.js in the repo or connect automatic publishing later.
